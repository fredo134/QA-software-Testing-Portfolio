# 🚀 API Testing with Postman & Newman

This folder contains automated API test suites, Postman collections, environment configuration files, and Newman execution reports.

---

## 📂 Directory Structure

- [📂 collections/](./collections/) - Exported Postman Collection JSON files
- [📂 environments/](./environments/) - Postman Environment JSON files
- [📂 reports/](./reports/) - HTML test execution reports generated by Newman CLI
